Claude 桌面 app 新建会话时的 ==folder== 是会话的工作目录，决定 Claude 在哪里读写文件、执行命令、往上逐级加载 `CLAUDE.md` 等等。

而 ==Environment== 是两类的统称：

第一类：机器，例如 this computer、WSL、docker desktop 等。只决定会话跑在哪里，用哪里的 shell 和文件系统。

第二类：官网名为“preset”，是一个能绑定很多配置项的组合，包括：

- 机器、文件夹；

- 模型、effort、权限模式；

- worktree 开或关的选择；

  > Worktree 是 git 的功能：从同一个仓库再签出一份独立副本，并放在新分支上。
  >
  > - 开了以后会话只改副本，不碰原目录，几个会话也能并行改同一个仓库；
  > - 不开就直接改原文件夹。
  >
  > 它只对 git 仓库里的文件夹有意义。
  >
  > 子目录也能开 worktree，app 签出的是整个仓库，并切出新分支，而会话的工作目录是副本的根目录，不是副本里的子目录。

- 环境变量

等等。
