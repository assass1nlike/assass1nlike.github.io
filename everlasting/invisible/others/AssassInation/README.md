# AssassInation

> 本文件夹用于研究：在今天以及可预见的未来里，有什么是 AI 做不了的，是我作为一个人类的创造能感受到意义和永恒的？

## 一段话的结论

"AI 做不了什么"这个问法，答案会随每次模型发布而缩水；把意义建在它上面，等于把自己的意义外包给一个每半年刷新一次的外部指标。更稳的问题不是"它做不到什么"，而是"什么是'做到'这个词根本不适用的事情"。

存在一层这样的东西：AI 生成的是**类型**（一篇好文章、一个好证明），而意义活在**个例**里（这一篇、这一夜、这个人）。类型可以被无限复制，个例在定义上只有一个。这不是能力差距，是范畴差异——把一个类型做到完美，也不会让它变成个例，因为它没有位置、没有时间、没有指向，也没有什么东西对它构成风险。

由此推出两个可检验的预测，见 [practice.md](practice.md)：AI 产出的价值，正比于其价值有多"功能性"；人产出的价值，正比于其价值有多"索引性"。以及一个实操判据：**这个选择是不是承重的？**

至于"永恒"——你得不到"被永远记住"，那本来也不是谁真得到过的东西。《左传》讲三不朽，标准是"虽久不废"，是**久**，不是永；而它明确否定了"保姓受氏"（血脉延续）算不朽。真正稳固的那种 permanence 不是时长，是**不可撤销**：一件已发生的事，无法被再变成没发生。你证出来的那个定理，在你死后、在没人记得你之后、在所有档案都焚毁之后，仍然为真。
