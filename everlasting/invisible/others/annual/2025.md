# 1.感受

## 1.1 控制感受

长期以来，人们都面对自律问题的困扰。单说最常见的有关中学生学习的自律，各大社交媒体上就能找到广泛讨论。这其中，不乏有挂着“学不进去？一招本质让你自律”的标题，实则推销猎奇教辅的视频，颇像是学姐今天同你谈理想谈家庭谈生活，明天让你办校园卡。人们已经可以从这个话题中夹带私货进而牟利了，可见它随处可见，又没有理想的或一致的答案。

在很久之前，大约是我七年级下学期时，得年级第一的那段时间，我对这一系列问题不屑一顾、嗤之以鼻。那时的我意气风发，或者说走火入魔，沉浸在课内考试排名霸榜带来的前所未有的正反馈，以及相应的良性循环之中。我在小学阶段的考试从未体验过“排名”，因此那时的我惊异地感受着拥有极好的这一指标所带来的认可、夸赞、崇拜，像是被囚禁十八年后猛地穿越进了洞房花烛夜。我感到很困惑，为什么会有人做不到自律。

不过，其实只有在学生时代，人们才会看重成绩 [^1]，伴随着这种现象发生的，就是上述密集型正反馈的减少：未来很难遇见这种全体以一个目标（高分）为追求，并且给足你上述情绪价值的环境。而除去外部因素，于我个人而言，也像是洞房花烛多了就成了新的囚禁，本就在减少的正反馈已经不能带给我怎样的冲击了。此时，我发现过去那个一时激发出的无所不能的自己正在死去，我也要面对自律问题了。

这就引出了这一节的标题，控制感受。这一理论，就是为解决自律问题而产生的。为了解释它，我暂且把一个人的状态分成“想法”和“感受”两部分，这也是 1.2 内容的基础。想法就是你的意识，“自律很重要，我应该自律”。感受则是身体里各种化学物质的作用，让你注意力集或不集中，感到愉悦而自信亦或是它的反面。二者显然共同作用，都对自律问题等有影响。

首先提出的是，感受会影响想法。想法常常基于对事物重要性的判断，但感受也有重要性，会被纳入考虑范围，进而影响想法的形成。

自律想法的形成，是来源于对自律指向的好结果的认识和了解。比如我想，“自律会让我得到...，这是很重要的”。不过，当前放纵爽了也很重要，因为这是真爽啊。在这里，你的感受会决定你对这份爽的渴望程度，从而决定对这份爽的重要性的判断。

同时，我们的行为也不是非此即彼的，并不是自律的重要性 > 放纵爽的重要性，进而就投身自律，而是并行式的。这很像是我最近一篇论文涉及的数据筛选，并不是就使用得分高的数据而不用低的，而是说高得分数据有更高的概率被选中用于训练 [^2]。人类行为与之有些许神似：自律有更高的重要性，进而就把更多的时间放在自律上。说到这里其实已经很明确了，为了让指导我们行为的想法给自律赋予更高的权重，就要调整自身的感受，不要让自己处于一个一心想着放纵的状态，进而让放纵的重要性被拉高。

我写到这里的时候又身临其境地模拟感受了一下，那种真实的无法自律的感觉似乎也并不源自想法上的误判，自己心里“自律远重要于放纵”的想法门儿清，但就是会复习到B站。但我觉得此时理论仍然是成立的，只是放纵被分配的权重不是很清晰地在思绪中呈现，而是换成了这种方式。此时在想法层面，放纵的重要性其实已经压倒式战胜了自律，量变引起质变，直接跳过大脑接管你的双手。

不过，对感受的权重分配诚然深受当前状态的影响，也可能因此有剧烈的浮动，但如果我们想要探究正确的分配方式，或者说客观看待对放纵的需求应该是怎样的，正确的答案是什么呢？我认为，随着习惯的改变和塑造，这都是可变的，进而任何一个设定值都是合理的。由此，引出下一节。

## 1.2 习惯

习惯是存在于我们身体设计里的一个特性，让我们有适应的能力。在 1.1 的比喻中，初时的囚禁可能痛苦万分，但十八年的习惯适应下也会大大减缓；洞房花烛多了就逐渐不是穿越后的极乐，而成了新的囚禁。（那再适应新的囚禁，又成了极乐，然后又成了囚禁，难道洞房花烛的本质是余弦函数？）

与 1.1 中提到的感受一样，很多习惯背后也是一通化学反应在支撑，例如某物质浓度过高身体就会提高其阈值。不过也与那一小节提到的想法类似，有的习惯完全是基于思维的。它们不存在或仅有微量的生理支持，主要是自己经常做某事进而形成的行为惯性。

改变后一种习惯，重点在你能否跳出过往行为的思维定式，打破自己制成的行为枷锁。比如，在放纵日你的胃袋向大脑说今天确实是不用吃了，你能否跳出“放纵日(—>多吃)—>爽”这个引导你鬼使神差又去硬吃的隐形内在驱使？问题不在身体感受的影响，而是自我意志的改变。

显然这比改变前一种习惯简单，因为那在含有生理上阻碍的同时，思想上的上述惯性同样存在。例如克服刷B站，不光要对抗大脑生成的那二两物质，内在的“有空刷刷手机”的想法上的习惯也需要被消除。

我们应当把握住想法层面上相对简单的改变机会，以此来避免放纵、达成自律。一种方式是防微杜渐，在习惯没有加深到产生生理支持的时候切断，例如在身体对尼古丁的渴望还没到丁真的程度，仅仅是有抽烟的想法时，抓紧戒掉。

另一方式，是人为制造或抓住一个没有生理感受作为欲望加持的状态，用这个时机来改变。例如，某个时刻我的注意力被猎奇短视频彻底榨干，视听感官离开手机的一毫秒都让大脑瘙痒不堪。此刻要想破局，我既要打破在视频结尾时小手上划、刷下一个的行为惯性，还要同我那个一直喊着“想要了”、憋得脸红流泪翻白眼的大脑对抗。这时，若是强迫自己视线离开屏幕五分钟，身体对多巴胺的渴求感就会显著降低，欲求不满的大脑酱也逐渐平静了下来，你不再是挣扎着让自己不刷视频，而单纯是在做一个此刻刷或者不刷视频的决定，伴随着一个行为惯性，就是过去你每遇这种情景，都选择了刷。

上述的五分钟冷静是人造的窗口期，而也有一些自然的时机可以被抓住。例如刚刚起床的时刻就相当不错，视觉记忆模块都没怎么加载好，欲望模块更是没发育起来。此时起手就是刷视频，会破坏窗口期，让自律快进到困难模式。说句题外话，起床瞬间看手机，还会对神经系统产生损害 [^3]。

是的，在没有生理加持的状态下选择放纵，通常也会促使其形成，“本来不想，现在想了”；这也是所谓“xx只有零次或无数次”的部分原因。

在学生时代，有不少窗口期是被要求强制进入的；在抱怨的同时，可以利用一下这种强制性来改变自己。毕竟，若非强制，我可能在五分钟冷静的第三分钟就觉得改变自己也不怎么重要，然后继续为我的大脑沟壑精卫填海。

## 1.3 封神

封神理论也与自律问题有关，并且我在 23 年终总结里给出了详尽的证伪：忽视中途的努力、要求自我检查和判定、忽略不可抗力的影响、异化奋斗的目标。而今年我领悟到了一个更加简单，又似乎更加本质的原因：你和我，没那么厉害、没那么自律。我们是人，封不了神。

相对地讲，今天的我和明天的我多半不会有很显著的变化。bro 今天不自律，心里想着最后放纵一通明天一定自律。此刻的你是被打倒的，但明日你会遇到一模一样的考验，那不还是输？此外，“最终の狂欢放纵”对自律并没有正向促进作用，反而会帮助身体建造对未来放纵的生理感受加持，参考 1.2 的最后两段。

绝对地讲，无论在什么时刻，达到封神的标准都是十分困难的。那就像苦行僧式的修行，但我们是人，女娲设计出来就是奔着吃好睡好玩好的，很难做到。即使我们心里知晓当下的修行是为了更爽地在未来吃睡玩好，若是尚有在此时此刻接触一点点它们的能力，我们依旧容易败给欲望。

与这一原理有些相似的是，人很难做成锦上添花的事情，以及只能带来隐性收益的事情。比如我觉得低体脂肌肉真的太帅了，可是吃了一顿健身餐就开始质疑它的意义，比如我觉得人读了五十本书会有巨大的收获，可是感觉这种收获并不存在就是我最大的收获。人类的代码设计就是无脑，朝着它关心的“摄入两千大卡能量”这种目标多绕一点弯路，就要疯狂压力你，让你思考这么做有什么意义。我觉得这能在一定程度上解释，行至半途者十有八九。

然而，我认为，做好这二者——锦上添花的事情、带来隐性收益的事情，对成事至关重要。尤其尤其是在你开始质疑这样做的意义时，坚持下去，这可能是胜过他人的关键。你的大脑最关心的两千大卡，人人都能吃到；但它所质疑，以及无数个夜晚的你所质疑究竟有没有意义的东西，是人人之外的你。

# 2.追求

## 2.1 感官感受

这一节中，我暂且把大脑的白月光，两千大卡，以及与进食类似的一切自然产生的生理欲望，例如 1.2 提到的刷视频的欲望，统称为“感官感受”。

这一大节的标题是“追求”。在 1.3 所说的，大脑所认为的追求，那就只有感官感受。可是，就像 1.1 开头提到的，我面对排山倒海前所未有的认可、夸赞、崇拜，也感觉爽的很，这和感官感受一样，也值得追求啊。类似地，在马斯洛的需求层次理论里，身处高位的那几条也不怎么是感官感受。

不过在我的心目中，它具有很高的地位。感官感受那是真的爽，实实在在的舒适感，这一套欲望满足的舒适感是编写在基因里的。像所谓的缸中之脑，一直通电来提供快感，我认为那绝对是夯。若非感官感受如此美妙，为什么还要第一节的有关自律的讨论，还是因为它的诱惑之大，满足之深让人无法自拔。

叔本华说“人总是在欲望和无聊之间摇摆”，诚然，如果感官感受能保证被填满，那的确无聊，会去关注其它追求。不过，包括我在内的大部分人的感官感受都不能被时刻满足，常常幻想着一个极乐无虑的日子的降临。如果细想我们一直以来所做的一切事情的最终指向，我觉得十有八九还是感官感受。

可见，虽然被主流地认为是“肤浅”“肉欲”，感官感受的满足在我看来不可否认是非常不错、令人向往的。

而又一个值得一提的，我同样认为令人向往的事物，是一个对感官感受的延展，我称之为“新奇感受”。它的意思就是，做从未体验过的事情，无论好坏，获得的新奇体验。

它与感官感受不等同，比如有些新奇感受虽然是前所未有的体验，在感官感受视角来看却是一种折磨。它之所以令人追求，一定程度上是因为满足了我的好奇心理与探索欲望。这背后的原理或许有一系列心理学理论来解释，不过总归是，它们触及到了大脑代码中反复强调的生存需求欲望以外的，事关好奇与探索的部分。

## 2.2 永恒

上一小节反复地讲了满足感官感受有多么爽，然而一来，我们大多不易将其完全满足，反而是一些比它“高尚”的追求更容易实现；二来，完全满足后也需要其它的追求来填补叔本华所言的“无聊”。所以，在这里我将谈论一个感官感受之外的追求，我称之为“永恒”。它的含义容易理解，创造永恒的事物，为世界留下些永远存在的东西。

在大一上的哲学通识课里，老师曾问，在今夜十二点就将死去的你，会做些什么。同学的回答中，完全选择满足感官感受的少之又少、有一部分与新奇感受有关、而大多数回答，都离不开永恒。

我在24年终总结的第三节中谈到了它的存在，当时是以游戏作为引子，说“我不甘心仅余下这些，而是要留有真正的永恒之物”。不过，当时的文字尚有不准确之处，因为把永恒从字面意思解释，认为客观层面上能被一直保留的即是永恒，我觉得并不恰当。

我们追求的永恒要做到被他人看见，不然也只是一直被保留的自娱自乐。因而，24 年终总结把音游制谱归结到这一项追求中，并不准确，或许“新奇感受”这个分区要更恰当些；反过来讲，客观上不能保留却一直被人铭记的也是永恒的例子，“遗忘才是终点”。

那于我个人而言，要想创造永恒，应该如何做呢？最先想到的途径就是我的“主业”，作为人工智能专业的学生，进行科研产出。这是效用很高的一种做法，既有达成永恒的机会，也是实现感官感受的核心途径：若真是做成了有影响力有意义的工作，那确实是为科学发展带来了能被一直延续的智慧；如果水出来几篇顶会论文，那也会带给未来更高的薪资，进而捞的米又能用来极视听之娱，满足感官感受。

在二六年一月，凭着饮下一瓶无糖可乐的饭后偶然想出的 idea，我完成了自己的第一篇工作，投稿 ICML2026。它研究的是一种数据筛选策略，通过选择梯度满足一定条件的数据，surprisingly 获得了下降明显更快的验证损失。

此外，在本节，就像 24 年终总结时我提到了 AI 谱面生成和高维拓扑识别两个项目，我也要分享一下新一年里打算进行的一些很帅的项目。

1. poincare conjecture 与视频剪辑中的“转场”，以及 diffusion 模型的结合。

正如我B站账号“刺客喜欢”在 2025.8.19 发布的视频取得了八十万播放、四万收藏的爆火，这个项目的 novelty 必然会获得更大的关注。同时，我在初三、预一的时间里花费了大量时间学习代数拓扑，一个纯数学领域的内容。但是，在以统计、以数据、以没那么严肃的数学为基础的人工智能领域，它们可以说是没有一点用处。因此，这个项目也是对我过往学习积累的一个难得的应用，回应我艰辛学习纯数学留下的执念，切实做到我B站的个性签名——“给抽象的数理知识找到应用”；切实做到 assassinlike 这个名字的第三、四条理由——感受抽象数理的魅力、并借助视频平台等给自己带来收益。

说起拓扑学与我的人工智能专业，还真有一些研究，把拓扑学应用到AI中，e.g.利用持续同调等知识，添加新模块到传统卷积神经网络中，增加对图片分类的准确度 [^4]。但坦白讲，这些一看就很 tricky 的东西是真的不怎么 applicable，我感觉这样做出来的工作也只能是上文所说的“一直被保留的”，而不是“永恒的”，并不太能达成我想要的追求。但是，我还是会在这一年了解一些这类文章，一是不忘初心，二是真的很好奇，把 homology 这种东西应用到 AI 中，到底是怎么做到的。

我即将列举出的第三个项目，也与拓扑学和 AI 有关。

2. 把我的算法结合 agnostic learning，实现高维的 computer vision.

这个项目其实就是 24 年终总结的“高维拓扑识别”的一个更加有应用性，更加可实现的迭代结果。在调研文献时，我了解到 agnostic learning 之后，立即就想到了它与我高维视觉识别算法的结合。广读论文真的很重要，很多我们想到的或困惑的事情，其实都有前人研究过，利用好已有结果能少走弯路。

3. 训练模型，用以处理以同胚为基础的空间推理任务。

在一些视频中，绳结在不剪断不粘接的条件下，轻拢慢捻抹复挑一通操作，就能从一种图案巧妙地变作另一种；有些益智玩具如智力扣也是类似，穿过此环、套上彼圈，就能把锁死的铁扣解开。

单说绳结这个例子，由于没有剪断和粘接，只是进行简单的操作，那么得到的不同图案就应该在某种程度上是等价的。这种等价关系就是同胚，“简单的操作”就是同胚变换。理解看似不同的图形间彼此同胚的性质，是处理一些问题的关键，我要训练模型去理解它。

这三条以外，还有些很帅的项目没有提及，它们同样大都不是我主业的 AI 科研内容，而是用于我的B站账号发展。是的，今年我将开始用心经营它，一方面是为了一个更火的自媒体账号，积累一些隐形的收益和资源，另一方面是让自己的研究和涉及抽象数理知识的项目让更多人看到，从单纯的能被一直保留，进化成永恒。

## 2.3 权重分配

感官感受和永恒这两种追求的含义都被阐明，都很美好都很带派。那我对此会如何选择，对它们的权重分配是怎样的呢？

这个答案在近几年常常改变。我最意气风发的时候，感受着 1.1 所述正反馈带来的情绪价值等快感，觉得感官感受完全就是路边，低级的很，为我带来的快乐远远不及前者。这种心态促使着我学习了更多高深的知识，感觉自己必将为科学做出贡献，因此也觉得永恒这一项是很重要的。

而最近这一年我愈发意识到，一个能做到永恒的贡献几乎是不可能达成的，哪怕是较我更强的人也难以做到。这时我再去看自己学习纯数的那段经历，当时心怀的想要做出伟大成果的愿望就是不了解实际情况而产生的幻想，那段时间我只是吸收和输入世界上已有的知识，感受着理解抽象概念和复杂证明的一种领悟知识的快感，觉得未来真正做出些什么，也与之一样令人愉悦和简单。

随着轻易创造永恒这种想法的幻灭，以及 1.1 所说的正反馈的减少，我的心态发生了变化，不再像当时那样富有激情地学习和研究，反而认为感官感受的满足似乎是更实际的快乐来源。然而，这个过程在外部看来就是所谓的堕落，而且与我先前两年的想法完全矛盾；我自己又是一个相信坚持的力量，且不甘于平凡的人，因此又觉得要把感官感受之外的追求提高权重。

那么，最终我选择怎么分配呢？我是这样想的：

首先，除去一些很纯粹的对永恒的追求，我的那些看上去并非浅显地满足感官感受，而是事关更高追求和目标的所作所为，其实最终指向也是一样的，如 2.1 所述。其次，我做不到对此选择跳过中间商，因为现在没能力去全力满足感官感受，那些更高一级的追求是必经之路。再者，于这些必经之路中，我亦可以顺便获得许多快乐，或是创造永恒的贡献、或是收割满 1.1 所言的情绪价值——拥抱夸赞与崇拜、或是诠释 assassinlike 这个名字的第四条原因——感受数理科学的魅力、或是感受长期努力终于达成目标的迸发爽感。

由这些推导，我的答案也明确了：专注于那些最终指向是感官感受，却更高一层，呈现为事业和成就的事情；艰苦奋斗，努力达成目标和梦想（但2030百大有些过于离谱）；为了更好做到这些，减少多余的对感官感受直接和赤裸的满足。

诚然，我深深意识到许多目标都是十分困难的；但每每思绪掠及它们，我最先想到的还是记忆中无所不能的自己，如行乎竹林，观细雨紫烟。
