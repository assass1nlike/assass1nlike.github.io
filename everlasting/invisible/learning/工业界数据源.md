# 工业界数据源清单

这份文档只收现在能开通或买到的来源。每条写清楚：给什么数据、怎么拿到、大致什么价、通常拿来做什么。价格是 2026 年中的量级，具体以官网为准；写"销售"的意思是得联系销售报价，一般没有公开价目表。

获取方式只有四种，后面不再重复：自助注册刷卡即用；API key 按量计费；销售合同年付；公开免费。知道这一点，比记住几十个名字更有用。

## 搜索、网页与抓取

**SerpApi**（serpapi.com）：把 Google、Bing、YouTube、Google Maps 等搜索结果返回成结构化 JSON。自助注册，免费 250 次/月；付费 $25/月 1000 次起，按量递增到约 $3750/月 100 万次。用途：SEO 与关键词研究、品牌提及监测、把搜索结果当成一种行为数据来研究。

**DataForSEO**（dataforseo.com）：同类 SERP 和 SEO 数据，按请求计费，单价比 SerpApi 低一个数量级，适合大规模跑批。用途：批量抓搜索排名、本地商家、关键词数据。

**Bright Data**（brightdata.com）：代理网络加现成抓取 API。住宅代理按流量，列表价约 $8/GB，量大能压到 $3/GB 上下；Web Unlocker 按请求，约 $1.5/1000 次；另有数据集市场按记录卖。开通要过 KYC。用途：抓有反爬的站点，电商、招聘、房产这类。

**Oxylabs / Zyte / Apify**：Oxylabs 偏代理，Zyte 偏抓取和结构化解析，Apify 是爬虫应用市场，上面有现成的 Actor 可以直接跑，按次或按月。用途：不想自己维护爬虫时直接买。

**Common Crawl**（commoncrawl.org）：每月一次的公开网页存档，PB 级，免费下载。用途：预训练语料、大规模网页文本研究。

**Wayback Machine**（archive.org）：网页历史快照，有公开 API。用途：研究网页随时间的变化、找回已删除内容。

## 企业与工商

**企查查开放平台**（openapi.qcc.com）：中国企业的工商、股权、司法、经营数据 API。按次计费，常见接口单次 0.1 到 6 元，例如模糊搜索约 0.1 元、工商照面约 0.2 元、全维度核验约 3 元；另有"企业户"模式，按企业数包周期、不限调用次数。用途：企业图谱、供应链尽调、信贷和招聘场景的公司核验。

**天眼查**：同类，开放 API 加会员制网页版。

**OpenCorporates**（opencorporates.com）：全球企业注册数据，免费 API 有限额，商业用途付费。用途：跨国实体匹配。

**Dun & Bradstreet**：企业信用与 D-U-N-S 编码，销售。用途：B2B 信用评估、企业主数据。

**ZoomInfo / Apollo / Cognism**：B2B 联系人和企业信息库，订阅制。用途：销售线索、组织架构。

**Crunchbase / PitchBook / Preqin**：融资、并购、基金和 LP 数据。网页版订阅每年几百到几千美元，API 和批量数据单独谈。用途：创投研究、公司生命周期。

## 金融与另类数据

**SEC EDGAR / FRED / EIA**：免费。财报原文、宏观序列、能源统计，都有 API。用途：金融 NLP 底稿、宏观建模。

**Bloomberg / LSEG / FactSet**：终端加 API，每个席位每年一到数万美元。覆盖行情、财报、分析师预期、新闻。用途：量化研究、事件研究。

**Wind / 东方财富 Choice / 同花顺 iFinD**：中国市场对应物，终端年费约一万到数万元人民币。用途：A 股和宏观研究。

**Consumer Edge / Affinity Solutions / Earnest Analytics**：信用卡和借记卡交易面板，按周或按天更新，销售，年费通常几万美元起。用途：估算零售公司周度营收、nowcasting、财报前建仓。

**Numerator / NIQ / Circana**：收据面板和零售扫描数据，销售。用途：品类份额、铺货、价格弹性。

**Similarweb / Semrush**：网站流量、渠道结构、关键词。网页版每月一百多美元起，API 单独计价。用途：竞品流量分析、市场进入研究。

**QuestMobile / 艾瑞 / 易观**：中国 App 和移动互联网数据，销售报价。用途：用户规模和时长、行业报告。

**Ortex / S3 Partners**：做空兴趣和证券借贷数据，订阅制。用途：拥挤度分析、对冲基金持仓。

## 电商、消费与零售

**Keepa**（keepa.com）：亚马逊历史价格和排名 API，订阅买 token、按请求消耗。用途：价格战监测、选品、消费行为研究。

**Helium 10 / Jungle Scout**：亚马逊卖家的选品和关键词工具，月费几十到几百美元。用途：跨境电商选品、竞品销量估算。

**蝉妈妈 / 飞瓜数据**：抖音、快手、小红书的达人和带货数据，订阅制，按版本和时长报价。用途：直播电商研究、达人营销效果。

**生意参谋 / 京东商智**：平台自家的商家后台数据，需要开店账号。用途：店铺经营分析。

**魔镜市场情报 / 久谦咨询**：中国电商和消费品的销售与份额数据，销售报价。用途：品类规模、渠道结构。

**Meta Ad Library / Google Ads Transparency Center / TikTok Creative Center**：免费，查在投广告的素材、投放方、起投时间。用途：广告创意研究、竞品投放、政治广告监测。

## App、流量与广告

**Sensor Tower**（sensortower.com）：App 下载量、收入、留存估算。data.ai 在 2024 年并入后统一到这个品牌。销售，年费通常上万美元。用途：移动市场分析、竞品监测。

**Appfigures**（appfigures.com）：同类，有自助档位，价格低不少。用途：小团队做 App 市场监测。

**Pathmatics / AdClarity / MediaRadar**：广告花费和渠道估算，销售。用途：营销预算基准、渠道份额。

**Similarweb API / Semrush API**：把上面网页版的指标程序化拉取，按查询量计费。用途：批量做竞品监测。

## 社交与舆情

**X API**（developer.x.com）：X 现在以按量计费的 credit 计费，读写分别定价，读帖大约每千条几美元量级，旧的免费和基础档基本退场。用途：舆情、事件传播。

**Reddit API**：非商业用途有免费额度，商业用途单独谈。用途：社区讨论、产品反馈。

**Bluesky / Mastodon**：开放协议，可以直接拉全量 firehose，免费。用途：社交网络结构研究。

**YouTube Data API**：免费额度加配额制。用途：视频元数据、评论。

**TikTok Research API**：面向学术机构申请，免费，覆盖公开视频和评论。

**Brandwatch / Talkwalker / Meltwater / Sprinklr**：商业舆情监测，销售，年费从几万美元起。用途：品牌监测、危机预警。

**新榜 / 清博 / 微热点**：中国社媒和内容数据，订阅制。用途：公众号、微博、短视频传播分析。

## 位置、遥感、航运与航空

**Placer.ai**（placer.ai）：手机定位推算到访量、客群、停留时长。没有自助购买，销售报价；公开合同显示第一年约 1.2 万到 3.4 万美元，有功能受限的免费版。用途：零售选址、商业地产估值、客流预测。

**Advan（原 SafeGraph）/ Foursquare / Veraset**：POI 和移动面板，销售。用途：兴趣点研究、人口流动、选址。

**Planet / Maxar / SkyFi**：卫星影像。Planet 按监测面积和更新频率打包，销售；SkyFi 可以自助按平方千米下单，适合小规模任务。用途：农业估产、基建监测、灾害评估。

**Sentinel / Landsat**：免费公开影像。用途：长时序地表变化。

**Kpler / Vortexa**：油轮和天然气船跟踪与库存估算，销售。用途：大宗商品交易、能源库存预测。

**MarineTraffic / Datalastic / AISHub**：船舶 AIS。AISHub 免费但要贡献数据，另两家订阅制。用途：港口吞吐、供应链监测。

**OpenSky**（opensky-network.org）：免费，全球航班和 ADS-B。**Cirium / FlightRadar24** 是商业版，字段更全。用途：航空运力、旅游分析。

**高德 / 百度地图开放平台**：POI、路径规划、地理编码，免费额度够研究用。用途：城市空间分析、选址。

## 安全、软件供应链与链上

**Shodan / Censys**：互联网设备和服务扫描库，免费层有限，付费按月。用途：暴露面研究、资产测绘。

**GreyNoise / VirusTotal**：威胁情报，社区版免费，商业版付费。用途：恶意 IP 和样本分析。

**crt.sh / Certificate Transparency**：免费，证书透明度日志。用途：发现子域名、追踪证书签发。

**deps.dev / Socket / Snyk**：开源依赖和漏洞数据，部分免费。用途：软件供应链风险。

**Dune / Flipside / Glassnode / Nansen**：链上数据查询和分析。Dune 和 Flipside 有免费层，Nansen 和 Glassnode 偏订阅。用途：加密资产研究、地址行为分析。

## 预测市场与赔率

**Polymarket Gamma API**（gamma-api.polymarket.com）：免费、不需要 key，返回市场、事件、价格历史。用途：事件概率、舆情预期，把市场共识当成一种标注。

**Kalshi**（kalshi.com）：受监管的事件合约交易所，有 API，行情免费，交易要开户和 KYC。用途：宏观和事件预测。

**The Odds API**（the-odds-api.com）：体育博彩赔率聚合，免费 500 次/月，付费按量。用途：体育预测、市场效率研究。

## LLM 语料、标注与评测

**Common Crawl / FineWeb / Dolma / The Pile**：免费，预训练语料和清洗流程的公开版本。

**Reddit / Stack Exchange 数据转储**：Reddit 免费层对非商业有额度，Stack Exchange 每季度全量转储免费。用途：对话和代码语料。

**Scale AI / Surge AI**：人工标注、SFT、偏好数据、红队，销售。用途：RLHF 数据、领域专家数据。

**Mercor / Handshake AI / Turing**：专家网络，按小时付费，平台抽成。用途：博士、医生、律师级别的高质量回答和评判。

**Outlier**（outlier.ai）：面向个人的标注平台，注册即可接任务。用途：个人体验工业标注流程。

**Prolific / CloudResearch**：学术友好的众包，按参与者分钟计费加服务费。用途：可控的问卷和标注实验。

**Vals AI / Patronus / Braintrust / LangSmith**：评测和观测平台，部分有免费层。用途：领域评测、回归测试、线上观测。

## 使用上的坑

**按量计费会失控。** SERP 和代理类 API 的价格差主要来自速度档位和并发档位，跑批前先算清 QPS 和单价，不要用默认档位直接开跑。

**销售报价通常有最低合同期。** Placer、Similarweb、Kpler 这类基本是年付，试用期短，采购要走合同。学术身份能拿到折扣的只有少数，比如 Planet 和部分遥感供应商，大部分不区分。

**合规边界看合同和辖区。** 抓公开数据和绕过登录墙是两件事。2024 年几起抓取诉讼里法院支持了抓公开数据，但违反服务条款仍然可能构成违约。企业数据和个人数据（位置、征信）在很多辖区另有额外限制。
