这个角度很有意思——你抓住了 ARC-AGI-3 的一个核心设计思想：**没有先验、没有说明书，模型必须从零开始通过交互理解环境规则**。这其实是一个独立于"agent 工具调用"的难度维度。让我搜一下符合这个思路的 benchmark。找到一组很对你思路的东西。这些 benchmark 的共同设计哲学就是：**模型空降到一个新环境，规则要么完全没说、要么需要从交互中推断**。和 ARC-AGI-3 是同一族。

## 最直接对应：BALROG（最契合你思路的旗舰）

BALROG 把六个强化学习游戏环境聚合成一个统一测试平台：BabyAI、Crafter、TextWorld、Baba Is AI、MiniHack、NetHack 学习环境。

关键设计点 ——BALROG 难以通过简单记忆解决——所有环境都是程序化生成的，不太可能两次遇到同一个实例。这点和 ARC-AGI-3 的"无说明书 + 抗污染"思路完全一致。

按"是否需要推断环境动态"来排序，**最契合你思路的子环境是**：

- **Baba Is AI**：基于热门游戏 Baba Is You，玩家通过推动文字块来操纵游戏规则本身，改变物体如何交互。这是字面意义上的"规则在变化，模型必须在交互中重新发现规则"。
- **MiniHack** 和 **NetHack**：MiniHack 和 NetHack 这两个子任务套件对所有模型都极具挑战，特别是 quest 和 boxoban 任务从未被任何模型解决。NetHack 尤其残酷——人类玩家不借助攻略需要数年才能掌握 NetHack。
- **Crafter**：Minecraft 风格的 2D 网格生存，需要探索 + 资源 + 制作链。

整体结果是当前顶尖 LLM 在最简单任务上表现尚可，但在 MiniHack 和 NetHack 这样的困难任务上完全无法取得有意义的进展——这正好就是 ARC-AGI-3 那种"前沿模型< 1%"现象的另一个体现。

## 思路相近的其他 benchmark

**Jericho Benchmark**（基于 Infocom 经典文字冒险游戏）：Jericho 基准仍然是一个未解决的硬探索问题，文本游戏环境提供两个基本挑战：部分可观察性（要求 agent 从局部文本描述构建世界模型）和组合状态-动作空间。例如 Zork1 的游戏词汇有 697 个单词、最多五词命令，导致每步约 $1.64 \times 10^{14}$ 种可能动作。完美的"零先验 + 部分可观察 + 必须从交互中建模"。

**AQA-Bench**：关键特征是交互式评估协议——例如在 DFS 中，每个节点的连接边只有当模型遍历到该节点时才可见，这要求 LLM 能记住已访问节点并规划后续动作。算法版本的 ARC-AGI-3，把"探索"的形式化抽象出来了。

**ALFWorld / ScienceWorld / TextCraft**（家用环境、科学规律发现、合成配方）：ALFWorld 涉及高层指令下的家居导航和物体操作；ScienceWorld 要求 agent 通过与复杂模拟世界的交互来发现并应用科学规则；TextCraft 测试在隐藏配方结构下的资源收集和多步合成。ScienceWorld 特别有意思——它要求模型**自己通过实验发现物理/化学规律**。

**LLM-Cave**（Wumpus World 现代版）：agent 必须通过对附近危险的推理来探索环境并避免潜在损失。在洞穴中，agent 只能获取当前格子的信息，而附近的坑和 wumpus 可能杀死它。附近的坑和 wumpus 会产生微风和臭味。LLM 应当根据观察到的微风和臭味信息推理出坑和 wumpus 的位置。轻量级的"部分可观察 + 因果推断"测试。

## 一个更深层的发现

有篇 2026 年 4 月的论文标题就很直白——"**LLMs Lack Environmental Curiosity**"（LLM 缺乏环境好奇心）。研究发现：discovery（发现）并不是瓶颈——基于 LLM 的 agent 持续地发现了相关的意外信息，但选择忽略它们。这种交互行为在三个 benchmark、多个 LLM 和 agent 框架上是一致的。

这个发现挺关键的：**当前 LLM 在新环境里失败，不是因为它们没看到关键信息，而是因为它们倾向于执行预设的模式而不去整合新观察。** 这某种程度上解释了为什么 ARC-AGI-3 上分数那么惨——不是不知道，是不会"在交互中重新学习"。

## 一个 framework 化的看法

把"特定环境 + 新环境操作"这条线拆开，大致有三个独立的难度轴，每个都有对应 benchmark：

| 难度轴         | 含义                         | 代表 benchmark                               |
| -------------- | ---------------------------- | -------------------------------------------- |
| **规则隐藏度** | 规则是给出的还是要交互推断的 | ARC-AGI-3、Baba Is AI、ScienceWorld、Jericho |
| **可观察性**   | 全局可见还是部分可见         | NetHack、Jericho、LLM-Cave                   |
| **时间跨度**   | 几步够了还是要数百步规划     | NetHack（数十万步）、Crafter、MiniHack       |

**ARC-AGI-3 在"规则隐藏度"上拉到了极致**（没有任何文字说明）；**NetHack 在"时间跨度+可观察性"上拉到了极致**；**Baba Is AI 把"规则本身就是可操纵物"做成了游戏机制**。三者从不同方向逼近同一个核心问题。

如果你想做这个方向的调研或者评测设计，我建议从 **BALROG + Jericho + ScienceWorld** 三件套入手——它们覆盖了上面三个轴，而且都有公开实现可以直接跑。
